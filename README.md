# Opus 5.5 动效片库

**22 条可溯源的 Claude Opus 5.5 动效案例：15 个视频型动效、7 个交互网页。** 每条都能看演示、复制提示词，并回到原作者的出处。

[在线打开片库（飞书秒搭，无需登录）](https://zcnofdpgpxud.feishuapp.com/app/app_17exzr8eka4/)

![动效片库首页预览](docs/preview.png)

## 怎么用

1. **先看效果：**打开上方在线片库，选择卡片进入详情。视频型演示可播放和拖动时间线；网页型演示可直接交互。
2. **再取提示词：**详情页可复制提示词，也可以下载[提示词合集 PDF](docs/Opus55-22条动效提示词-小红书附件.pdf)，或阅读[文字版](prompts.md)。
3. **本地打开：**在 GitHub 选择 **Code → Download ZIP**，解压后用 Chrome 打开根目录的 `index.html`。保留 `demos/` 文件夹与首页的相对位置。

部分演示依赖在线字体或 cdnjs 的 Three.js；断网时这些演示可能缺字体或无法完整运行。如果浏览器限制本地 `file://` 页面内的 iframe，可在解压后的目录运行 `python3 -m http.server`，再打开 `http://localhost:8000`。

## 内容与出处

- 22 条均保留作者、平台、日期和来源链接；其中 **21 条提示词标为原文，1 条标为摘录**。摘录不作为完整原文展示。
- 片库中的预览是依据提示词和虚构示例输入制作的**演示版**，不是原作者发布的成片。每条详情中的「溯源」可查看原出处。
- 页面里的“视频型动效”是可播放、可拖动时间线的 HTML 演示，不是原作者的视频文件。演示中用到的虚构品牌和示例数据均为演示输入。
- 本仓库收录的是片库发布文件和提示词整理，不包含原作者的视频、未经整理的调研材料或另一本地 100 案例图鉴。原作者的提示词及外部内容仍归各自权利人所有；本仓库不对这些内容授予统一的再使用许可。
